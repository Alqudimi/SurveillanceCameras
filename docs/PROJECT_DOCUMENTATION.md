# Project documentation

## Overview

This repository contains a camera-surveillance prototype with separate `backend/` and `frontend/` areas, a notebook, sound assets, and an existing README.

## Development

Follow the dependency and startup instructions in the root README and inspect both service directories for their local entry points. Keep camera input configuration and notification credentials in environment variables.

## Privacy and safety

Use the system only with appropriate authorization. Apply access control, encrypted transport, minimal retention, secure storage, audit logging, and clear disclosure to people who may be recorded.
